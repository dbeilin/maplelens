# Pin EXP to Every Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Pin button on the EXP tab that keeps a one-line EXP readout at the bottom of every other tab.

**Architecture:** The line's text is a pure function in `exp_meter/text.py`. `Box` gets a generic footer slot (it knows nothing about EXP) that shows only with the tabs and never on its owner's tab. `ExpMeterTool` owns the line widget and the Pin button, and reaches the box only through callbacks that `app.main` wires, as the path tool's `allow_typing` lambda does.

**Tech Stack:** Python, PySide6, pytest (offscreen Qt).

**Spec:** `docs/superpowers/specs/2026-11-14-pin-exp-design.md`

## Global Constraints

- Off by default; saved as `settings["pin_exp"]`, a new key in `store.DEFAULTS`.
- Line copy: label `EXP`; text `{pct:.2f}%/h · Lvl in {eta}`, `Measuring…`, `Paused`, `Can't read bar` (accent), `Waiting for game`; a trailing accent `›`.
- Button copy: `Pin` while off, `Unpin` while on; a `secondary_button`, next to History.
- Tools stay independent: `Box` must not import or name anything from `tools/`.
- Don't change `version` in `pyproject.toml`. Run `uv run ruff check`, `uv run ruff format`, `uv run pytest`, `uv run python scripts/check_screen_only.py` before each commit.

## Review Focus

- The longest line (`100.00%/h · Lvl in 99h 59m`) must fit `TAB_W` on both platforms → fit test in Task 3.
- The box jumps to Quests by itself (`QuestFocus`): the line must show there, since it goes through `select` → Task 2's `test_footer_follows_select`.
- The status line ("Looking for MapleStory…") or About replacing the tabs must hide the line, and it must come back after → Task 2 tests.
- A settings file saved before this feature has no `pin_exp`: `load_settings` fills it from `DEFAULTS` → Task 3 reads `settings["pin_exp"]` and the test builds from `DEFAULTS`.
- Rapid Pin/Unpin must leave the button text, the setting and the footer agreeing → Task 3 test toggles twice.
